Commanding Discovered Styles:
Weakly Supervised Motion Discovery for Compositional Control

Anonymous Authors — Submission to ICRA

Abstract

Robot motion control in complex settings requires adopting different motion styles on demand while tracking user-specified task commands. However, composing styles and commands is challenging: motion styles are difficult to implement analytically and reuse across platforms, while recorded motion data typically contain entangled combinations of embodiments, motion regimes, and constraints. We present a framework for compositional motion control that derives a repertoire of styles from motion recordings and enables a shared controller to express those styles while following independently specified user commands. First, motion recordings from multiple sources are expressed on a common target embodiment. Second, a weakly supervised style discovery module extracts candidate styles using an ensemble consensus representation and density-based clustering, organizing observed motion into reference pools without prescribing the repertoire size. Third, a shared controller is trained using reinforcement learning, conditioned on an observed style reference alongside an independent task command. We evaluate the framework on a quadruped robot across repertoire coherence, commandability, and style expressibility measured via reference consensus cosine, and demonstrate mechanically distinct style execution on physical hardware.

Framework Overview

The pipeline decouples style discovery from policy execution through three stages, enabling on-demand style conditioning under arbitrary independent task commands:

Stage 1

Common Target Embodiment

Motion data from multiple sources (including retargeted animal movements and teleoperated runs) are executed and recorded on a common quadruped platform to ensure kinematic realizability.

Stage 2

Weakly Supervised Discovery

An ensemble of temporal convolutional encoders learns an orthogonal-invariant consensus spherical geometry. HDBSCAN extracts 16 candidate styles and groups windows into reference pools without manual cluster thresholds.

Stage 3

Compositional Controller

A shared reinforcement learning policy is conditioned on a selected reference consensus code alongside independently commanded velocities, learning to retain the requested style while following task commands.
