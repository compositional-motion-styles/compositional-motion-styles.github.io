Abstract

When a robot has more degrees of freedom than a task constrains, multiple executions can achieve the same objective with distinct motion styles. Compositional robot control aims to preserve a selected style while following an independent task command, balancing potentially competing objectives. However, explicit style definitions can depend on platform-specific assumptions, while recordings entangle embodiments and constraints.

In this paper, we present CODES, a framework for compositional robot control that discovers a coherent style repertoire from diverse recordings and composes it with independent commands. Motion retargeting maps the recordings to motions executable by the target robot; weakly supervised consensus encoding and density-based clustering identify styles within and across recordings without a prescribed count; reinforcement learning trains a policy to compose them with independent commands.

A Unitree Go2 case study evaluates decomposition and control through baseline comparisons, two simulators, and hardware deployment. The motion collection combines mocap recordings with policy executions based on retargeted motions from animals and other robot platforms. CODES improves kinematic coherence over the no-coarse-guidance and VQ-VAE baselines. The controller tracks velocity commands beyond estimated recorded support in simulation and exhibits distinguishable style characteristics in cross-simulator and hardware executions.

System Architecture

Framework Overview

The CODES pipeline systematically decouples motion style discovery from reinforcement learning policy execution through three modular stages (Paper Section 3).

Figure 1: Pipeline of the proposed CODES framework. A: Unpaired motion recordings across diverse embodiments and gaits are executed on a common robot platform to obtain realizable trajectories. B: Temporal convolutional encoders learn an orthogonal-invariant consensus spherical geometry; density-based clustering (HDBSCAN) identifies style clusters without prescribing cluster count. C: A shared RL policy is trained with sigmoid-gated style and velocity rewards to track independent task commands while expressing the conditioned style reference.
1

Common Target Embodiment

Heterogeneous source recordings (including dog and horse motion captures, solo quadruped rollouts, and teleoperated executions) are projected onto the target Unitree Go2 embodiment, enforcing realizable kinematic and joint limits before representation learning.

2

Weakly Supervised Discovery

An ensemble of 10 temporal convolutional networks is trained under pairwise consensus constraints. HDBSCAN extracts 16 distinct candidate style clusters with hierarchical density boundaries, grouping motion windows into robust reference pools.

3

Compositional Controller

A multi-objective RL controller is conditioned on an active reference consensus code alongside independently specified forward, lateral, and heading velocity commands, allowing the operator to steer arbitrary velocity profiles while enforcing distinct gaits.

Hardware Verification

Robot Deployment

Live physical deployment on the Unitree Go2 robot showing style execution under continuous operator commands. The policy, reference bank, and InEKF state estimation run onboard the Jetson without external motion capture or offboard inference (Paper Section 4.4).

Unitree Go2 Physical Hardware · Sliding Telemetry Overlay 1080p HD Video

The synchronized telemetry display exhibits 60 Hz onboard estimates of commanded forward velocity \(v_x\), lateral velocity \(v_y\), heading rate \(\omega_z\), joint torque excursions, and kinematic foot ground-contact states over a trailing 4-second sliding window. The policy is safeguard fine-tuned for 2,000 iterations with joint targets clipped to 0.025 rad within physical limits, matching deployment safeguards. The mission switches sequentially through styles C04 (low crawl), C00 (horse-derived trot/walk), C14 (forward jumps), and C11 (sit down/up) at a fixed \(0.5\) m/s forward command.

Independent Task Steering

Continuous velocity tracking from live operator joystick input, navigating variable planar vectors without compromising gait stability.

Consensus Style Cosine

Style fidelity is measured causal-window-wise via reference consensus cosine, retaining style affinity throughout active maneuvers.

Zero-Shot Sim-to-Real

Direct policy transfer with domain randomization on contact friction, motor damping, and link inertia without sim-to-real fine-tuning.
